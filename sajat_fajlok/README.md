# Saját fájlok

Ez a mappa Marcsi saját fájljainak tárhelye: ide bármit fel lehet tölteni (dokumentumok, képek, feladatlapok,
prezentációk). A weboldal nem használja és sehol nem hivatkozik rá.

## Feltöltés a GitHub oldalán

1. Nyisd meg ezt a mappát a GitHubon.
2. Kattints az **Add file → Upload files** gombra.
3. Húzd be a fájlokat, majd alul kattints a **Commit changes** gombra.

Almappákat is létrehozhatsz: **Add file → Create new file**, a névhez írd be például `tortenelem/jegyzet.md`.

## Jó tudni

- A böngészőből egy fájl legfeljebb 25 MB lehet.
- A tároló nyilvános, ezért amit ide feltöltesz, azt bárki megnézheti, aki ismeri a címét. Személyes adatot,
  jelszót vagy dolgozatjegyeket ne tölts fel ide.
- Ezt a `README.md` fájlt ne töröld, különben az üres mappa eltűnik a GitHubról.
